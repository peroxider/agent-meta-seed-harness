## 2. Frozen decisions

| Area | v0.1 decision |
|---|---|
| Runtime | CPython 3.12、asyncio、单机单writer daemon |
| Python naming | distribution/repository `agent-meta-runtime`；import/source `agent_meta_runtime`；CLI `agent-meta`；Protobuf package `agent_meta.*` |
| External Seed | independent repository/distribution `agent-meta-seed-harness`；import `agent_meta_seed_harness`；only Seed → public Runtime SDK/RPC dependency；checkout path is never protocol identity |
| Store | SQLite STRICT authoritative schema + filesystem CAS；短事务、WAL、FK/trigger开启 |
| Public transport | 4-byte big-endian length framed Protobuf v1；Linux/macOS UDS，Windows Named Pipe；同OS user peer auth |
| Backend | language-neutral Backend v1 contract；InMemory/Portable为产品切片，AgentOS为client + fake contract gate |
| Identity/encoding | UUIDv7、UTC microseconds、SHA-256 lowercase hex、RFC 8785约束、AMPAK1 |
| Mutation | CommandEnvelope、expected revision、single UoW、Fact + outbox、MutationReceipt |
| Task | durable queue；接纳时冻结 serving Composition、State refs、Surface与budget；terminal不可逆 |
| Authority | Ed25519 Root、显式Grant/history/counter、每次effect前重新检查；无隐式Root bypass |
| Capability | versioned descriptor/SPI、显式trust placement、确定性compatibility report、pre-serving health probe |
| Composition | desired/serving/realized三指针；Reconciler完成后原子serving cutover |
| State | immutable revisions + mutable CAS ref；migration先生成未绑定revision，再与serving原子切换 |
| Effects | EffectIntent reservation/settlement；至少一次delivery下不重复结算；unknown fail closed |
| Recovery | stable request/dedupe id、Backend inspect/reconcile、Fact hash chain、checkpoint、backup/restore |
| Scratch | required IPython isolated kernel adapter；禁止pickle/closure promotion，只允许source export |
| Evolution | deterministic v0 criteria/world/fake model；Promotion只改desired；自动Root succession延期 |
| Security | structured allowlist redaction、envelope encryption、OS credential store、Portable不宣称strong sandbox |

没有留给实现者的关键架构选择。允许裁量的仅是私有代码组织、等价索引优化、非协议日志文案和UI排版，边界以主规范41.59.5为准。

## 4. Implementation sequence

详细步骤、交付物和退出门禁见[`../plans/v0.1/README.md`](../plans/v0.1/README.md)。每个slice只有在本slice contract/golden/negative tests通过后才进入下一slice；允许并行编码，但合入顺序保持以下依赖：

1. **[Foundation](../plans/v0.1/Runtime_00_Foundation.md)**：项目骨架、architecture lint、canonical encoding/ID/clock、error model、config和daemon lock。
2. **[Store](../plans/v0.1/Runtime_01_Store.md)**：authoritative migration、UoW、CAS/AMPAK、Artifact encryption、Fact chain/checkpoint、integrity doctor。
3. **[Semantic core](../plans/v0.1/Runtime_02_Semantic_Core.md)**：Identity/Epoch/Principal、Action/Invocation/Task、RuntimeView、reflection/context projection。
4. **[Authority and composition](../plans/v0.1/Runtime_03_Authority_Composition.md)**：Grant/history/counter、Capability descriptor/surface、Composition validation、Managed State。
5. **[Execution](../plans/v0.1/Runtime_04_Execution.md)**：Backend proto/client、InMemory与Portable worker、claim/cancel/process tree、effect reservation。
6. **[Control plane](../plans/v0.1/Runtime_05_Control_Plane.md)**：outbox、Reconciler、health probe、atomic state/serving cutover、crash recovery。
7. **[Interfaces](../plans/v0.1/Runtime_06_Interfaces.md)**：local RPC、CLI、pagination/upload/operations、readiness/backpressure。
8. **[Harness and Scratch](../plans/v0.1/Runtime_07_Harness_Host_Scratch.md)**：公共Harness Contract/SDK、install/activate/deactivate/uninstall、test-only Conformance Harness、IPython adapter、source-only export；外部Seed不在本序列中。
9. **[Evolution baseline](../plans/v0.1/Runtime_08_Evolution.md)**：Candidate/World/Experiment/Evidence/Evaluation/Promotion/Rollback。
10. **[Release closure](../plans/v0.1/Runtime_09_Release_Closure.md)**：backup/restore/upgrade/GC、Linux/Windows E2E/fault/security matrix、SBOM/provenance、trace audit。

外部Seed按[`Seed_Harness_00`](../plans/v0.1/seed-harness/Seed_Harness_00_Project_Bootstrap.md)至[`Seed_Harness_03`](../plans/v0.1/seed-harness/Seed_Harness_03_Integration_Release.md)独立实施为最小可发布闭环（由S03发布门禁闭合），文件可整体复制到Seed仓库；其状态不参与Runtime步骤门禁。S04–S07（[真实Provider](../plans/v0.1/seed-harness/Seed_Harness_04_Real_Model_Providers.md)、[工具Capability](../plans/v0.1/seed-harness/Seed_Harness_05_Capability_Toolset.md)、[会话模型](../plans/v0.1/seed-harness/Seed_Harness_06_Conversation_Sessions.md)、[Evolution Capability](../plans/v0.1/seed-harness/Seed_Harness_07_Evolution_Capability.md)）是外部Seed侧的后续能力波次，各自按S03流程独立发布新版本AMPAK，不改变Runtime v0.1范围与门禁。

外部Seed开发交接补充（2026-10-30）：实施链在S01与S02之间增加[S01A公共Host接入门禁](../plans/v0.1/seed-harness/Seed_Harness_01A_Public_Host_Contract.md)，完整输入/交付/验证见[Seed开发交接](../plans/v0.1/seed-harness/Seed_Harness_Development_Guide.md)与[Seed追踪计划](../plans/v0.1/seed-harness/Seed_Harness_Traceability.md)。SDK管理入口存在不表示执行期Host/State/凭据/演化创建入口均已交付；所需缺口由Runtime版本化关闭后Seed才可集成，禁止访问私有store或用fixture替代产品证据。本次仅补实施计划，不新增或修改冻结的Public/Harness Contract。

## 5. Definition of done

Release candidate只有同时满足以下条件才可标记v0.1：

- 主规范和traceability的ID集合严格相等，每个ID恰好一次；所有Required row有存在且通过的named proof。
- Public与Backend `.proto`、JSON Schema、SQLite migration、builtin AMPAK/lock和golden fixtures进入版本控制。
- 主SQLite DDL和Portable Backend DDL能在声明的SQLite版本实际加载，migration/trigger/integrity tests通过。
- Linux与Windows在Seed仓库/网络均不存在时从空环境安装wheel，完成init → core-ready revision 0 → 安装Conformance Harness → serving-ready fake Task → deactivate/uninstall → restart → backup/restore。
- AC-M01～M09B、M12～M16、M18～M47、M49～M54全部阻塞Runtime；AC-M10/M11保持deferred；AC-M17/M48只阻塞外部Seed且不得进入Runtime发布结论。
- crash points、重复delivery、权限race、state migration/write race、clock jump和旧owner迟到提交全部通过。
- release manifest记录OS/Python/SQLite/schema/protocol/package版本、依赖hash、SBOM/provenance、test evidence hash和已知deferred features。
- Operator runbook覆盖init、start/stop、doctor、repair dry-run/apply、key recovery/rotation、backup/restore、dead-letter和UNKNOWN effect处置。

## 6. Planning audit result

截至v0.1-r11，已知会影响互操作性、安全边界、持久化兼容、恢复正确性或验收结论的决策均已在主规范冻结；Runtime不得探测或依赖外部Seed checkout，跨仓库CI只消费显式版本化的公共contract。当前没有需要产品负责人补充的关键输入。后续若业务范围新增跨多个外部package拼装单一Composition、真实Provider、联网Capability、多租户或production AgentOS部署，应作为v0.2/M4+变更，不得隐式扩大v0.1。S04–S07规划的外部Seed能力（真实Provider、工具Capability等）即属于该后续波次：由Seed仓库独立承载、独立发布，Runtime v0.1的验收边界与发布结论不受影响。
